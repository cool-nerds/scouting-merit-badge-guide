# Troop 48 · Lynnfield, Massachusetts

Merit Badge Counselor Parent Toolkit

[Open the parent website](https://cool-nerds.github.io/scouting-merit-badge-guide/) · [Open the new counselor form and directory](https://cool-nerds.github.io/scouting-merit-badge-guide/counselor/) · [Read the full GitHub handbook](counselor/HANDBOOK.md) · [Download PDF](counselor/handbook.pdf)

The original twelve-step guide is supplemented with a searchable national badge directory, individual qualification profiles, detailed examples, and a multi-badge applicant worksheet. The directory snapshot reviewed November 15, 2026 contains 143 current profiles and one separately flagged discontinued-badge transition entry.

## How parents use it

1. Match their experience to badge profiles and read the official requirements.
2. Select badges and describe qualifications, certifications, specialist partners, facilities and gaps.
3. Download the text supplement or print their completed form to PDF.
4. Complete and sign the official council MBC form and obtain the required unit or district approval.
5. Submit through the council membership process and wait for council confirmation.

This site does not certify, approve, register or submit applications. It has no council or Scoutbook integration. Do not commit applicant records, certificates, CORI material or medical information to this public repository. Email drafts are opened only by the visitor; nothing is sent automatically.

## Source files

- `index.html`: original twelve-step guide with a link to the expanded toolkit.
- `counselor/index.html`, `style.css`, `app.js`: accessible static form and directory.
- `counselor/badges.js` and `badges.json`: the same editorial badge profiles in browser and reusable data formats.
- `counselor/HANDBOOK.md`, `handbook.html`, `handbook.pdf`: repository, accessible print and PDF versions.

The original guide uses browser-local checklist storage. The new applicant form uses optional device storage; otherwise entries remain only in the current page. No backend or third-party scripts are used. Review current council procedures, official badge changes, safety rules and qualifications before each update. Current membership web instructions resolve routing and fees that conflict with legacy wording retained in the council-linked PDF; ask council to confirm unresolved differences.

## Validation for this release

Browser checks cover directory completeness, filtering, retired-badge exclusion from new requests, multiple badge notes, opt-in persistence, escaping, exported supplements, print output, clearing and mobile width. Verify the GitHub Pages deployment after publishing.
